# Bundled app fonts

Literata titles (normal and italic), Figtree body (normal), variable weights 500–700.
Latin and Latin extended subsets are stored locally, with their SIL Open Font licenses.
No Google Fonts requests are made by the app.

Downloaded from the Google Fonts CSS API on 2026-10-21.
