# App icon

Approved by Owen on 2026-10-21. Made with the built-in image generation tool, then resized
with Pillow (Lanczos). All versions are opaque square PNGs; iPad adds its own rounded corners.

- `enchanted-book-source.png`: original approved image, 1254 × 1254.
- `enchanted-book-1024.png`: reusable 1024 × 1024 master.
- `icon-512.png`, `icon-192.png`: manifest icons.
- `apple-touch-icon.png`: 180 × 180 iPad Home Screen icon.
- `coloring-book-*` and `botanical-book-*`: earlier design options, kept for reference.

Only the three small app icons are included in the offline download; the masters are not.

## Prompt used for the approved edit

Use case: precise-object-edit. Edit this botanical coloring-book app icon. Preserve the existing
square composition, deep forest/sage green background, centered open ivory book, muted botanical
greens, fine paper texture, two tiny gold sparkles, uncluttered negative space, and the contrast
of line art on the left page and colored greenery on the right. Make only these refinements:
add a few very finely detailed living vines stemming into the book, curling naturally over a
page edge and subtly into the spine, with tiny leaf veins and elegant thin tendrils. Keep these
restrained and graceful, not a dense frame or wreath. Redesign the pencil to be visibly slimmer,
sleek and modern: clean refined pale-gold/brushed-champagne body, sharp green colored tip,
minimalist end cap. Wrap the pencil with a delicate living vine with a few tiny richly detailed
ivy leaves and fine curling tendrils. Make the pencil feel enchanted through a very subtle warm
light beneath the vine and a tiny luminous accent at the tip, not large magic swirls or bulky
decorations. Pencil remains diagonally across the right page in essentially the same position.
Intricate craftsmanship and leaf detail within the calm minimalist design. All important elements
fit safely inside the square for Home Screen icon cropping. Output an opaque square PNG,
1024x1024 if possible. No text, letters, names, logos, border, frame, watermark, UI mockup,
or baked-in rounded corners.
